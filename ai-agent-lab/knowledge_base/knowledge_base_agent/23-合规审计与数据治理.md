# 合规审计与数据治理

> 适用场景：面向企业客户的 Agent 系统，需要满足数据保护法规和企业安全审计要求
> 最后更新：2026 年 4 月

---

## 一、为什么 Agent 系统需要合规

Agent 系统处理的数据可能包含：
- 用户的个人信息（姓名、手机号、邮箱）
- 企业的商业机密（财务数据、客户名单、合同条款）
- 行业敏感数据（医疗记录、金融交易、法律文书）

这些数据受到多种法规约束，违规可能面临巨额罚款和声誉损失。

---

## 二、主要合规框架

### 2.1 GDPR（欧盟通用数据保护条例）

与 Agent 系统最相关的条款：

| 条款 | 要求 | Agent 系统的影响 |
|---|---|---|
| 数据最小化 | 只收集必要的数据 | 对话历史不应无限保留 |
| 被遗忘权 | 用户有权要求删除其数据 | 必须能删除特定用户的所有对话和向量 |
| 数据可携带权 | 用户有权导出其数据 | 必须能导出用户的对话历史 |
| 知情同意 | 用户知道数据如何被使用 | 告知用户对话会被 LLM 处理 |
| 数据驻留 | 数据存储在指定地区 | LLM API 调用可能跨境传输数据 |

### 2.2 SOC 2（服务组织控制）

企业客户常要求的安全认证：

| 原则 | Agent 系统的要求 |
|---|---|
| 安全性 | 访问控制、加密、漏洞管理 |
| 可用性 | SLA 保障、容灾方案 |
| 处理完整性 | 数据处理准确、完整 |
| 保密性 | 数据分类、访问限制 |
| 隐私 | 个人信息保护 |

### 2.3 行业特定法规

| 行业 | 法规 | 关键要求 |
|---|---|---|
| 医疗 | HIPAA | 保护健康信息（PHI），审计日志 |
| 金融 | PCI DSS | 保护支付卡数据，加密传输 |
| 政务 | 等保 2.0 | 分级保护，安全审计 |

### 3.2 审计日志实现

```python
import json
import logging
from datetime import datetime

audit_logger = logging.getLogger("audit")
audit_logger.setLevel(logging.INFO)

# 审计日志写入独立文件
handler = logging.FileHandler("audit.log")
handler.setFormatter(logging.Formatter("%(message)s"))
audit_logger.addHandler(handler)

class AuditMiddleware:
    """审计中间件"""

    def log_request(self, entry: AuditLogEntry):
        """记录审计日志"""
        audit_logger.info(json.dumps({
            "timestamp": entry.timestamp.isoformat(),
            "request_id": entry.request_id,
            "tenant_id": entry.tenant_id,
            "user_id": entry.user_id,
            "action": entry.action,
            "model": entry.model_name,
            "tokens": entry.input_tokens + entry.output_tokens,
            "cost": entry.cost_usd,
            "pii_detected": entry.pii_detected,
            "tool_name": entry.tool_name,
        }, ensure_ascii=False))
```

### 3.3 审计日志存储

| 方案 | 适用场景 |
|---|---|
| 文件日志 + 日志轮转 | 小规模，简单 |
| ELK Stack（Elasticsearch + Logstash + Kibana） | 中大规模，需要搜索和可视化 |
| 云日志服务（CloudWatch、Cloud Logging） | 云部署，免运维 |
| 独立审计数据库 | 强合规要求，审计数据与业务数据分离 |

## 四、数据生命周期管理

### 4.1 数据保留策略

```python
class DataRetentionPolicy:
    """数据保留策略"""

    RETENTION_RULES = {
        "conversation_history": {
            "default": 90,       # 默认保留 90 天
            "gdpr_request": 0,   # GDPR 删除请求立即删除
            "legal_hold": 365 * 7,  # 法律保留 7 年
        },
        "audit_logs": {
            "default": 365,      # 审计日志保留 1 年
            "financial": 365 * 7,  # 金融行业 7 年
        },
        "vector_embeddings": {
            "default": -1,       # 永久保留（跟随知识库）
        },
    }

    def should_delete(self, data_type: str, created_at: datetime, context: str = "default") -> bool:
        retention_days = self.RETENTION_RULES[data_type][context]
        if retention_days == -1:
            return False
        age_days = (datetime.now() - created_at).days
        return age_days > retention_days
```

### 4.2 数据删除（被遗忘权）

```python
class DataDeletionService:
    """用户数据删除服务（GDPR 被遗忘权）"""

    async def delete_user_data(self, user_id: str, tenant_id: str):
        """删除指定用户的所有数据"""
        deleted = {
            "conversations": 0,
            "checkpoints": 0,
            "vectors": 0,
            "audit_anonymized": 0,
        }

        # 1. 删除对话历史（Checkpoint）
        deleted["checkpoints"] = await self.delete_checkpoints(
            tenant_id, user_id
        )

        # 2. 删除用户上传的文档向量
        deleted["vectors"] = await self.delete_user_vectors(
            tenant_id, user_id
        )

        # 3. 审计日志匿名化（不删除，但去除个人标识）
        deleted["audit_anonymized"] = await self.anonymize_audit_logs(
            tenant_id, user_id
        )

        # 4. 记录删除操作本身（合规要求）
        audit_logger.info(json.dumps({
            "action": "gdpr_deletion",
            "tenant_id": tenant_id,
            "user_id_hash": hash(user_id),  # 只记录 hash，不记录原始 ID
            "deleted_counts": deleted,
            "timestamp": datetime.now().isoformat(),
        }))

        return deleted
```

```python
from cryptography.fernet import Fernet

class EncryptedField:
    """字段级加密"""

    def __init__(self, key: bytes):
        self.cipher = Fernet(key)

    def encrypt(self, plaintext: str) -> str:
        return self.cipher.encrypt(plaintext.encode()).decode()

    def decrypt(self, ciphertext: str) -> str:
        return self.cipher.decrypt(ciphertext.encode()).decode()
```

### 5.3 LLM API 调用的数据安全

| 风险 | 缓解措施 |
|---|---|
| 数据传输到第三方 | 使用 API 提供商的数据处理协议（DPA） |
| 数据被用于训练 | 确认 API 提供商不使用客户数据训练模型（OpenAI API 默认不用） |
| 跨境数据传输 | 选择数据驻留在指定区域的 API 端点 |
| 敏感数据泄露 | 发送前脱敏，接收后还原 |

## 六、PII 处理

### 6.1 发送给 LLM 前脱敏

```python
import re

class PIIProcessor:
    """PII 检测与脱敏"""

    PATTERNS = {
        "phone": (r"1[3-9]\d{9}", "[手机号]"),
        "id_card": (r"\d{17}[\dXx]", "[身份证号]"),
        "email": (r"[\w.+-]+@[\w-]+\.[\w.-]+", "[邮箱]"),
        "bank_card": (r"\d{16,19}", "[银行卡号]"),
    }

    def detect(self, text: str) -> list[dict]:
        """检测 PII"""
        findings = []
        for pii_type, (pattern, _) in self.PATTERNS.items():
            matches = re.finditer(pattern, text)
            for match in matches:
                findings.append({
                    "type": pii_type,
                    "value": match.group(),
                    "position": match.span(),
                })
        return findings

    def redact(self, text: str) -> tuple[str, dict]:
        """脱敏并返回映射表（用于还原）"""
        mapping = {}
        redacted = text

        for pii_type, (pattern, placeholder) in self.PATTERNS.items():
            for i, match in enumerate(re.finditer(pattern, text)):
                token = f"{placeholder}_{i}"
                mapping[token] = match.group()
                redacted = redacted.replace(match.group(), token, 1)

        return redacted, mapping

    def restore(self, text: str, mapping: dict) -> str:
        """从脱敏文本还原"""
        restored = text
        for token, original in mapping.items():
            restored = restored.replace(token, original)
        return restored
```

### 6.2 脱敏流程

```
用户输入："我的手机号是 13812345678，帮我查订单"
    ↓ 脱敏
发送给 LLM："我的手机号是 [手机号]_0，帮我查订单"
    ↓ LLM 处理
LLM 回复："已为 [手机号]_0 查询到订单信息..."
    ↓ 还原
返回用户："已为 13812345678 查询到订单信息..."
```
