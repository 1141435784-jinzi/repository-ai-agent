## 3. 数据留存策略

### 3.1 数据类型与留存期限

| 数据类型 | 留存期限 | 处理方式 |
|----------|----------|----------|
| 对话记录 | 90天 | 到期自动删除 |
| 用户Profile | 永久（除非用户删除） | 加密存储 |
| 访问日志 | 30天 | 定期清理 |
| 审计日志 | 永久 | 加密存储 |
| API调用记录 | 30天 | 聚合统计后删除 |

### 3.2 数据删除流程

```
用户请求删除
    │
    ▼
┌──────────────────┐
│ 验证用户身份    │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 删除对话记录    │  从数据库中删除
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 删除用户Profile │  从用户表中删除
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 删除相关日志    │  清理相关操作日志
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 发送确认邮件    │  通知用户删除完成
└──────────────────┘
```
