
# 安全设计文档

## 1. 数据分类标准

### 1.1 数据分类级别

| 级别 | 名称 | 描述 | 示例 |
|------|------|------|------|
| L1 | 公开数据 | 可对外公开的信息 | 产品介绍、文档 |
| L2 | 内部数据 | 仅内部人员可访问 | 系统日志、配置文件 |
| L3 | 敏感数据 | 需授权访问的信息 | 用户配置、API Key（加密） |
| L4 | 机密数据 | 高度敏感，严格管控 | 用户对话记录、个人身份信息 |

### 1.2 数据分类映射

| 数据类型 | 分类级别 | 存储要求 |
|----------|----------|----------|
| API Key（加密后） | L3 | 环境变量/密钥管理 |
| 用户对话历史 | L4 | 加密存储 |
| 用户Profile | L4 | 加密存储 |
| 系统配置 | L2 | 配置文件 |
| 知识库文档 | L1-L3 | 根据内容分类 |

## 2. 访问控制策略

### 2.1 RBAC 角色定义

| 角色 | 权限 | 说明 |
|------|------|------|
| 匿名用户 | 基础对话 | 无需认证，限制API调用频率 |
| 注册用户 | 完整功能 | 需登录，可访问个人数据 |
| 管理员 | 系统管理 | 可配置系统、查看日志 |
| 审计员 | 只读审计 | 可查看日志，不可修改 |

### 2.2 权限矩阵

| 资源 | 匿名用户 | 注册用户 | 管理员 | 审计员 |
|------|----------|----------|--------|--------|
| /api/chat | ✅ | ✅ | ✅ | ❌ |
| /api/sessions | ❌ | ✅ | ✅ | ❌ |
| /api/admin/* | ❌ | ❌ | ✅ | ❌ |
| /metrics/* | ❌ | ❌ | ✅ | ✅ |
| /health | ✅ | ✅ | ✅ | ✅ |

### 2.3 API 访问控制

- **速率限制**：匿名用户 10次/分钟，注册用户 60次/分钟
- **IP白名单**：管理接口仅允许内网访问
- **请求签名**：API调用需携带时间戳和签名

## 3. 数据脱敏规则

### 3.1 敏感信息识别

| 类型 | 正则模式 | 处理方式 |
|------|----------|----------|
| 手机号 | `1[3-9]\d{9}` | 脱敏为 `1xxxxxxxxx` |
| 邮箱 | `[\w.-]+@[\w.-]+\.\w+` | 脱敏为 `***@domain.com` |
| 身份证号 | `\d{17}[\dXx]` | 脱敏为 `******************` |
| 银行卡号 | `\d{16,19}` | 脱敏为 `**** **** **** ****` |
| 地址 | 包含省市区详细地址 | 脱敏为 `**省**市**区` |

### 3.2 脱敏流程

```
用户输入
    │
    ▼
┌──────────────────┐
│ 敏感信息检测    │  使用正则和NLP识别敏感信息
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 脱敏处理        │  按照规则替换敏感内容
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ LLM调用         │  传入脱敏后的内容
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 响应审核        │  检查响应中是否包含敏感信息
└────────┬─────────┘
         │
         ▼
    返回给用户
```

## 4. 数据加密策略

### 4.1 传输加密

- **HTTPS**：全站强制HTTPS，TLS 1.3
- **证书**：使用有效SSL证书
- **HSTS**：启用HTTP严格传输安全

### 4.2 存储加密

| 数据类型 | 加密方式 | 密钥管理 |
|----------|----------|----------|
| API Key | AES-256-GCM | 密钥管理服务 |
| 用户密码 | bcrypt (10 rounds) | 应用层处理 |
| 对话记录 | AES-256-GCM | 数据加密密钥 |
| 配置文件 | 环境变量 | 主机/容器安全 |

### 4.3 密钥管理

- 使用环境变量存储敏感配置
- 禁止硬编码密钥
- 定期轮换密钥
- 使用密钥管理服务（如 Vault）

## 5. 安全审计

### 5.1 日志记录

| 日志类型 | 记录内容 | 保留期限 |
|----------|----------|----------|
| 访问日志 | 请求时间、IP、路径、状态码 | 90天 |
| 操作日志 | 用户操作、时间、结果 | 180天 |
| 安全日志 | 异常访问、攻击尝试 | 365天 |
| 审计日志 | 管理员操作、配置变更 | 永久 |

### 5.2 审计要点

- 所有管理员操作需记录
- 敏感操作需二次验证
- 定期安全审计报告

## 6. 安全最佳实践

### 6.1 输入验证

- 对所有输入进行类型检查
- 使用参数化查询防止SQL注入
- 限制输入长度
- 过滤特殊字符

### 6.2 输出编码

- 对输出进行HTML/JSON编码
- 防止XSS攻击
- 使用安全的模板引擎

### 6.3 依赖安全

- 定期更新依赖包
- 使用安全扫描工具（如 Snyk）
- 禁止使用已知有漏洞的库

### 6.4 容器安全

- 使用最小化基础镜像
- 非root用户运行
- 定期镜像安全扫描
