
# 业务场景案例：长期记忆

## 场景概述

用户在多次对话中逐步完善旅行计划，系统需要记住用户的偏好和历史选择，提供个性化服务。

## 场景流程

### 第一次对话（周一）
```
用户：我计划下个月去杭州旅行。
系统：好的，请问您计划去几天？有什么特别想去的地方吗？
用户：大概3天，我喜欢自然风光。
```

### 第二次对话（周三）
```
用户：我之前说的杭州旅行，能帮我细化一下吗？
系统：当然！根据您之前提到的偏好（喜欢自然风光），我为您推荐以下行程：
      1. 西湖景区
      2. 龙井茶园
      3. 九溪十八涧
用户：太好了，能加上美食推荐吗？
系统：没问题！杭州的杭帮菜非常有名，我来为您推荐几家特色餐厅...
```

### 第三次对话（周五）
```
用户：我想调整一下行程，把九溪十八涧换成灵隐寺。
系统：好的，已为您调整行程。考虑到您喜欢自然风光，我保留了西湖和龙井茶园，同时添加了灵隐寺。
      需要帮您查询去灵隐寺的交通吗？
```

## 记忆机制

### 短期记忆
```python
# 对话历史（滑动窗口，保留最近N轮）
short_term_memory = [
    {"role": "user", "content": "我计划下个月去杭州旅行"},
    {"role": "assistant", "content": "好的，请问您计划去几天？"},
    {"role": "user", "content": "大概3天，我喜欢自然风光"},
]
```

### 长期记忆
```python
# 用户profile（持久化存储）
long_term_memory = {
    "user_id": "user_123",
    "preferences": {
        "travel_days": 3,
        "interests": ["自然风光"],
        "food_preferences": ["杭帮菜"],
        "budget": "medium"
    },
    "history": [
        {
            "date": "2024-01-10",
            "topic": "杭州旅行规划",
            "decisions": ["西湖", "龙井茶园", "九溪十八涧"]
        }
    ]
}
```

### 记忆检索流程

```
用户输入
    │
    ├─▶ 短期记忆检索（最近对话）
    │
    ├─▶ 长期记忆检索（用户偏好）
    │
    └─▶ RAG检索（知识库）
            │
            ▼
    融合所有信息
            │
            ▼
    生成个性化回复
```

## 技术亮点

### 1. 双层记忆架构
- 短期记忆：处理当前对话上下文
- 长期记忆：存储用户长期偏好

### 2. 记忆更新策略
- 自动识别用户偏好
- 定期更新用户profile
- 支持用户主动修改偏好

### 3. 记忆检索优化
- 使用向量检索匹配用户意图
- 支持模糊匹配和同义词
- 时间衰减机制（近期记忆权重更高）

### 4. 隐私保护
- 用户数据加密存储
- 支持数据导出和删除
- 符合GDPR规范

## 扩展能力

### 记忆存储后端
支持多种存储后端：
- SQLite（开发环境）
- PostgreSQL（生产环境）
- Redis（缓存）

### 记忆增强
- 添加情感分析（用户情绪检测）
- 添加主题建模（对话主题识别）
- 添加用户画像（更丰富的用户信息）
