
# 业务场景案例：工具调用链

## 场景概述

用户需要查询明天北京的天气，然后根据天气情况推荐合适的户外活动。这需要连续调用多个工具：天气查询 → 景点推荐 → 交通查询。

## 场景流程

### 初始请求
```
用户：明天北京天气怎么样？适合户外活动吗？
```

### 执行流程

```
用户请求
    │
    ▼
┌──────────────┐
│ Supervisor   │  判断需要调用天气工具
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  Tools Node  │  调用 weather_api 工具
└──────┬───────┘
       │ 返回：明天晴天，25°C
       ▼
┌──────────────┐
│ Supervisor   │  分析天气结果，判断需要推荐户外活动
└──────┬───────┘
       │
       ▼ 路由到 sights_agent
┌──────────────┐
│ Sights Agent │  查询适合晴天的户外活动
└──────┬───────┘
       │ 返回：颐和园、奥林匹克森林公园
       ▼
┌──────────────┐
│ Supervisor   │  判断需要进一步查询交通信息
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  Tools Node  │  调用 maps_api 查询路线
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  Summary     │  生成最终回答
└──────────────┘
```

### 工具调用详情

#### 1. 天气查询工具
```python
工具：weather_api
参数：{"city": "北京", "date": "明天"}
返回：
{
    "city": "北京",
    "date": "2024-01-15",
    "weather": "晴",
    "temperature": 25,
    "wind": "微风",
    "suggestion": "适合户外活动"
}
```

#### 2. 景点推荐（RAG检索）
```python
查询：北京 晴天 户外活动 景点
检索到文档：
- 颐和园：适合晴天游览，湖面风光优美
- 奥林匹克森林公园：适合户外活动，有大片草坪
```

#### 3. 交通查询工具
```python
工具：maps_api
参数：{"from": "天安门", "to": "颐和园", "mode": "地铁"}
返回：
{
    "route": "地铁4号线",
    "duration": "45分钟",
    "stations": ["西单", "西四", "动物园", "国家图书馆", "西苑"]
}
```

### 最终输出

```
明天北京天气晴朗，气温25°C，非常适合户外活动！

🌞 推荐景点：
1. 颐和园
   - 推荐理由：晴天时昆明湖波光粼粼，长廊漫步十分惬意
   - 交通：从天安门乘坐地铁4号线，约45分钟到达
   - 门票：30元

2. 奥林匹克森林公园
   - 推荐理由：有大片草坪和湿地，适合野餐、慢跑
   - 交通：从天安门乘坐地铁8号线，约30分钟到达
   - 门票：免费

建议您早点出发，避开人流高峰！需要帮您查询具体的出行路线吗？
```

## 技术亮点

### 1. 工具调用链
- 支持多步工具调用
- 前一个工具的输出作为下一个工具的输入
- 自动判断何时停止调用

### 2. 工具选择智能性
- 根据上下文选择最合适的工具
- 支持工具参数自动填充
- 工具调用失败时有重试机制

### 3. 上下文管理
- 工具返回结果自动加入对话历史
- 后续工具调用可访问历史结果
- 支持长对话中的上下文保持

### 4. 错误处理
- 工具调用超时自动重试
- 工具返回异常时优雅降级
- 向用户友好地展示错误信息
